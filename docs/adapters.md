# Adapter availability

The QLoRA adapters produced in this project are not stored in this Git repository because model weights can exceed GitHub's normal file-size limit. They will be published in Hugging Face together with a model card that records:

- base model identifier;
- training corpus;
- QLoRA hyperparameters;
- training environment;
- MIRAGE evaluation results; and
- intended research-only use.

The corresponding Hugging Face links will be added here when publication is completed.
