## Derived analyses

`analysis/` contains per-comparison CSV files and Markdown reports generated by `evaluation/analyze_mirage_changes.py`. For each base-adapter pair, it includes:

- aggregate and per-dataset accuracy;
- question-level improvement and regression labels;
- prediction transition matrices; and
- answer-option distributions.

## Logs

`logs/training/` contains the final Slurm output logs for the training runs. The JSON predictions are the authoritative source for reported metrics; logs are included as execution evidence.
